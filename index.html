02

Case studies

Problem → Built → Impact. Each one started as a firefight and ended as a permanent, reusable asset.

a.

Spec-driven, LLM-assisted pre-delivery QC

Problem

~1 in 3 client deliveries got flagged. The mechanical specs that would have caught them — filename schemas, character limits, metadata rules — lived in one person's memory, across 10–20 clients.

Built

Each client spec codified as machine-checkable rules, plus an LLM-assisted QC pass that validates every delivery before it ships. Proven with a retrospective harness replaying real past deliveries against the client's own verdicts.

Impact

58% of client-verified mechanical failures caught pre-ship on a 293-delivery retrospective — measured, not projected. New client onboarding became "add a spec," not "add a late night." Projected 0.6–0.7 FTE of rework eliminated at full scale.

b.

An agentic AI delivery pipeline, run by one operator

Problem

Thousands of localization jobs for a major streaming platform had to be manually pulled, submitted, QC'd, fixed, and delivered — order by order, by hand.

Built

End-to-end agentic automation: intake → cloud staging → submission → QC triage → 8-way parallel delivery → refix loop, with append-only audit logs. The recurring operations were then codified into fully autonomous, invocable agent skills.

Impact

1,854 jobs delivered at 98.6% acceptance, $145K revenue earned, batch turnaround cut from ~4 weeks to under 2, and volume scaled ~6× with zero added headcount — at ~$1 per job in AI cost.

c.

Private workflow → shared infrastructure

Problem

A production dubbing API was usable only by hand or through bespoke one-off scripts — the knowledge locked in one person.

Built

A 14-tool MCP server (TypeScript) exposing submit / update / cancel / usage / issues as first-class tools any AI agent or teammate can call — plus internal ops dashboards (FastAPI · SQLite · Streamlit).

Impact

A single person's capability became org-wide, agent-callable infrastructure — the concrete version of "AI adoption," not the slideware version.

d.

High-stakes compliance, zero-defect

Problem

Premium broadcast clients ship on strict, unforgiving multi-channel protocols; separately, a legal audit found hundreds of voice-consent records scrambled — on a deadline.

Built

Codified a major U.S. broadcast network's delivery SOP across three transport channels (email, Aspera, Signiant) with versioning and barcode schemas; built a programmatic re-matching pipeline for the waiver audit.

Impact

282 of 287 records re-matched under deadline; zero-defect deliveries on the company's most reputation-sensitive relationships.
